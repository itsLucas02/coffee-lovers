# 🍫 Chocolate Lovers Shop

A single-page web app for chocolate lovers and fans in Malaysia. Browse Malaysian-inspired sample chocolates, add them to a cart, tweak quantities, and review a simple order summary — all on one screen, with no backend, no login, and no payments.

**Live demo:** [https://itslucas02.github.io/coffee-lovers/](https://itslucas02.github.io/coffee-lovers/)

## About

Chocolate Lovers Shop is a lightweight front-end demo built as one self-contained HTML file. Everything runs in the browser: the product gallery, cart, and order summary are rendered from plain JavaScript with sample data, and nothing is saved between visits. It's ideal as a UI prototype, a teaching example, or a starting point for a real storefront.

The sample products are imaginary treats inspired by Malaysian flavours:

- 🥭 **Musang King Durian Truffle** — creamy durian ganache inspired by Pahang's durian season
- 🧋 **Teh Tarik Milk Chocolate Bar** — milk chocolate with a pull-tea caramel swirl, mamak style
- 🌿 **Pandan Gula Melaka Bites** — pandan praline with gula melaka coconut caramel

## Features

- **Add to cart** — tap a product and it appears in the cart preview with quantity 1
- **Remove item** — take any item out of the cart instantly
- **Update quantity** — change amounts with − / + controls; the cart and summary update immediately
- **Order summary** — a checkout-style review showing chosen items, total count, and a summary message (no payment is taken)
- **Never empty** — the page always opens with sample entries already visible

## Sections

The three sections stack down one page — no tabs, no navigation:

1. **Product gallery** — browse chocolate cards at a glance
2. **Cart preview** — see and edit what you picked without leaving the page
3. **Order summary** — review the pretend order before "imagining" a purchase

## Getting Started

No build step, no dependencies, no framework.

```bash
git clone https://github.com/itsLucas02/coffee-lovers.git
```

Then open `index.html` in any browser — or just visit the live demo link above.

## Tech Stack

- **HTML5** — semantic page structure in a single file
- **CSS3** — chocolate-themed styling with CSS variables, gradients, and responsive layout
- **Vanilla JavaScript** — cart state and rendering, no libraries
